# 이름: MinRTS

설명: 이 게임은 2D로된 군사전략 게임이다. Web에서 동작하며 핵심은 단순성이다.

# 게임설명

그래픽: 2D
심볼: NATO-APP6 (다 사용하지는 않고 간단하게.)
사용언어: Python + HTML/CSS/JS
기술: websockets을 기반으로 멀티플레이를 한다. (이거 멀티플레이는 나중에 일단 싱글플레이 레벨1 레벨2 이런식으로)

사용라이브러리: 
https://github.com/spatialillusions/milsymbol.git 심볼을위해

# 언어역할 분담

Python = 네트워크및 멀티플레이처리(HTTPS) + 가챠로직 + 게임핵심연산로직
핵심연산로직은 전투력 방어력 가챠확률 같은걸 말하는것이다.

HTML/CSS = 디자인

JavaScript = Python에 들어갈정도까지는 중요하지 않은 로직

# 게임시스탬

1. 최대 1200km까지 맵 랜더링이 가능하다.
2. 본부, 군단작전기지, 사단작전기지가 있다.
3. 본부가 함락되면 게임이 종료된다.
4. 군단작전기지가 함락되면 병력생성과 증원이 매우 느려진다.
5. 사단작전기지가 함락되면 병력생성과 증원이 조금 느려진다.
6. 최소 단위는 사단이며 사단 안에는 내가 직접 편제를 짤수있다
예: 기계화대대, 공병대대, 보병대대, 포병대대, 전차대대, 등등....(최소 20개)
7. 편제는 최대 4개 밖에 넣지 못한다

## 게임시스탬(전투)

전투는 기본적으로 아군 사단과 적 사단이 반경 20km안에서 만날떄 교전이 일어난다.
교전은 지형과 날씨, 편제에 따라서 승률이 매우 달라진다.
아군 사단이 이기고 있으면 점점 앞으로 나아가면서 아군점령 영토가 넓어진다.
(적군도 마찬가지)
